# 🧠 Mental Health Score

A Machine Learning project exploring the relationship between students' social media usage and mental health.

## 📌 About the Project

This project uses student social media and mental health data to explore patterns and build a machine learning model. Data analysis and model development were performed using **Google Colab**.

## ✨ Features

- 📊 Student social media and mental health data analysis
- 🤖 Machine Learning model for score prediction, if supported by the trained model
- ☁️ Google Colab for data analysis and model development
- 🌐 Streamlit application interface
- 🐍 Python-based implementation

## 🛠️ Technologies Used

- Python
- Pandas
- Machine Learning
- Google Colab
- Streamlit

## 📁 Project Files

- `main.py` — Main Python script
- `streamlit_app.py` — Streamlit application
- `ML_Project.ipynb` — Notebook exported from Google Colab
- `Mental_Health_Model.pkl` — Trained machine learning model
- `Student Social Media And Mental Health Impact.csv` — Dataset
- `ML Project (1).html` — HTML export, if applicable
